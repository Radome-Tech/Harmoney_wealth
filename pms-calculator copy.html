Formula Explanation

i = Opening NAV
ii = Gain = i × Return %
iii = Gross Value = i + ii
iv = Average AUM = (i + iii) / 2
v = Other Expense = iv × Other %
vi = Brokerage = iv × Brokerage %
vii = Management Fee = iv × Mgmt %
viii = Total Charges = v + vi + vii
ix = Value Before Performance Fee = iii − viii
x = Hurdle Value = i × (1 + Hurdle %)
xi = Performance Fee = (ix − max(HWM, x)) × Perf %
xii = Net Portfolio = ix − xi
